# AzenoHI frontend

React, TypeScript and Vite, adapted from the approved application starter.
See the [project README](../README.md) for setup, screenshots, architecture,
content editing, provenance and verification.

From this directory:

```bash
npm ci
npm run dev
npm run check
npm run test:e2e
npm run build
npm run preview
```

Use Node 26.13.1 and npm 12.2.2. No backend or environment variables are required.
Development uses port 5173 and production preview uses port 4173.
