## Earth textures

Source: [Solar System Scope textures](https://www.solarsystemscope.com/textures/),
by INOVE / Solar System Scope, based on NASA imagery and elevation data.
Distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Retrieved 2026-11-24:

- https://www.solarsystemscope.com/textures/download/2k_earth_daymap.jpg
- https://www.solarsystemscope.com/textures/download/2k_earth_nightmap.jpg
- https://www.solarsystemscope.com/textures/download/2k_earth_clouds.jpg

The scene refinement also uses the same author's 8K masters, downloaded on
2026-11-24 from the linked download page:

- https://www.solarsystemscope.com/textures/download/8k_earth_daymap.jpg
- https://www.solarsystemscope.com/textures/download/8k_earth_nightmap.jpg
- https://www.solarsystemscope.com/textures/download/8k_earth_clouds.jpg
- https://www.solarsystemscope.com/textures/download/8k_earth_normal_map.tif

All original JPEGs and the normal-map TIFF remain in design/textures/.
Production WebP variants are in web/public/textures/: 4096×2048 day/cloud/normal
maps (quality 79 / 60 / 86), plus an 8192×4096 night map (quality 88) to retain
fine city networks. The mobile tier uses 2048×1024 maps (day / night / cloud /
normal quality 75 / 82 / 67 / 82). Variants are resized with Lanczos from their
8K masters, then WebP-encoded. Normal data is sampled without sRGB conversion.
The shader repeats and offsets surface detail at twice its geographic density;
terrain normals, a separately elevated cloud shell, cloud shadows, twilight
color and analytic atmospheric falloff supply the depth and lighting. This is
an art-directed surface, not an accurate globe. The final Earth pass is reviewed
in earth-refinement.md; texture-manifest.json under docs/qa/earth-refinement
records the source TIFF and all runtime maps.
No ownership of these maps is claimed.

## Code-native visuals and typography

- Orbital station: original procedural geometry in stationModel.ts; no external GLB.
  Closed bevelled hulls, instanced plating/trusses/fixtures/windows, axial tower,
  docking undercarriage and aerials were reconstructed from the supplied image
  and decoded film crops. HDR reflections, brushed surface maps and the small
  rim-glint map are generated by code at runtime; no external texture license.
  Visually reviewed in Chromium at 1672×941 and 390×844, including moving frames.
  See scene-refinement.md for comparison evidence and remaining approximations.
- Brand mark and decorative path: SVG/CSS implementation of the supplied design. The diagonal Home ribbons were removed at the owner's request.
- UI icons: Lucide React, ISC license; package license retained with dependency.
- Inter Variable: Rasmus Andersson / Inter contributors, SIL Open Font License 1.1;
  locally served through @fontsource-variable/inter. License copied into docs/licenses/.
- README technology marks: local SVGs from the Simple Icons package, CC0-1.0.
- README banner/screenshots: captured from this actual application, not supplied mockups.

Keep production assets out of design/reference/ and preserve masters when replacing
variants. Inspect decoded images and rendered cards after any asset change.

Playwright README mark: Microsoft Playwright appIcon.png from the official GitHub
repository (packages/playwright-core/src/server/chromium/appIcon.png), Apache-2.0;
notice retained in docs/licenses.
